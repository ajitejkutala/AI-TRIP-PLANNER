## 📌 About the Project

AI Trip Planner is an AI-powered web application that generates personalized travel itineraries based on a user's destination, interests, trip duration, and preferred travel pace.

The application uses Large Language Models (LLMs) through Google Gemini and Groq to create structured travel plans, including sightseeing recommendations, local food suggestions, and activities organized by time of day.

Users can view their itinerary, copy it, print it, or download it as a PDF.

## ✨ Key Features

- 🌍 Destination-based travel planning
- 🎯 Personalized recommendations based on user interests
- 📅 Flexible trip durations
- ⚡ Relaxed, balanced, and fast-paced itinerary options
- 🤖 AI-generated travel recommendations
- 📄 Downloadable PDF itineraries
- 📋 Copy and print itinerary options
- 📱 Responsive user interface
- 🔄 Support for configured AI providers and fallback models

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, FastAPI
- **AI Integration:** Google Gemini API, Groq API
- **PDF Generation:** ReportLab
- **Libraries:** Pydantic, HTTPX, python-dotenv
- **Deployment:** Vercel

## ⚙️ How It Works

1. Enter your travel destination.
2. Select your interests and trip duration.
3. Choose your preferred travel pace.
4. Generate a personalized itinerary using AI.
5. View, copy, print, or download your travel plan as a PDF.

## 💡 Example Use Case

A traveler planning a one-day visit to Hyderabad can select history, local food, and photography as interests. The application generates a structured itinerary with suggested activities for different parts of the day, helping the traveler organize the visit more easily.
